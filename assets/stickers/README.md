# Sticker set — assets/stickers

Hand-authored SVG stickers for the dark "Russian 2000s underground" site.
Style: stroke width ~5, currentColor (recolor via CSS `color`), no width/height
attributes on the root, no defs/gradients/filters/fonts/external refs.
Icon files use `viewBox="0 0 120 120"`; texture files use their own viewBox
(noted below).
