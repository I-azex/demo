# ПОДЪЕЗД №9

Интерактивный сайт-подъезд: девять этажей, ноль лифтов, один выход.
Не портфолио. Художественная работа о памяти, молодости, сигаретах,
пиве, накотиках и людях, с которыми было тепло.

Собран вручную: чистый HTML, CSS и vanilla JS. Без сборщика, без npm,
без единой библиотеки. Шрифты лежат локально, фото — со свободных
лицензий Wikimedia Commons.

---

## Что внутри

**Этажи (скролл-история):**

| # | Секция | Что там |
|---|--------|---------|
| 09 | Вход | постер, неоновая вывеска, полароиды, скрытые надписи |
| 08 | Стена | коллаж фотографий с лайтбоксом |
| 07 | Магнитофон | плеер на три трека, WebAudio-анализатор, кассета |
| 06 | Тест | «Кто ты из подъезда?» — 4 вопроса и результат |
| 05 | Гараж | правила подъезда и генератор мудрости |
| 04 | Надписи | стена, на которой можно писать и двигать надписи |
| 03 | Пепельница | статистика действий и достижения |
| 01 | Выход | дверь на улицу и финальный оверлей |
| 00 | Подвал | секрет: найти, открыть, отпустить |

**Интерактив:**

- **Карман** внизу: сигарета, зажигалка, балтика, накотик.
  Клавиши `1—4` или клик по слоту. Выбранный предмет действует
  при клике по странице: дым, искры, пена, эффекты.
- **Зажигалка** — посвети по стене подъезда: проступают надписи.
- **Достижения** (11 штук), счётчики и прогресс — в `localStorage`.
- **Плеер**: три трека, перемотка, громкость, живой анализатор.
  Треки включаются по клику (браузер требует жест пользователя).
- **Тест** с четырьмя архетипами и копированием результата.
- **Стена надписей**: цвет маркера, перетаскивание, хранение в браузере.
- **Подвал**: открывается пятью кликами по двери, кликами по «18+»
  или словом «подвал» с клавиатуры.
- Прочее: кастомный курсор-окурок, дым, тосты, секретные слова,
  Konami-код, глассморфизм в HUD и скрытые надписи.

## Запуск

Достаточно открыть `index.html` в браузере — сайт работает и по `file://`.
Для полноценной работы шрифтов/маски/плеера лучше локальный сервер:

```powershell
python -m http.server 8781
# затем http://127.0.0.1:8781
```

Или любой другой статический сервер. Зависимостей нет.

## Управление

| Клавиша | Действие |
|---|---|
| `1`—`4` | выбрать предмет в кармане |
| `M` / `Ь` | включить/выключить звук |
| `Esc` | закрыть лайтбокс / оверлей |
| «подвал» | открыть секретную секцию |
| Konami-код | пасхалка |

Все анимации уважают `prefers-reduced-motion`. Сайт адаптивен:
на телефоне карман превращается в нижнюю панель, рейл этажей скрывается.
