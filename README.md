# ПОДЪЕЗД №9

**Живая версия: https://kozhuharyov.ru**

Интерактивный сайт-подъезд: девять этажей, ноль лифтов, один выход.
Не портфолио. Художественная работа о памяти, молодости, сигаретах,
пиве, накотиках и людях, с которыми было тепло.

Собран вручную: чистый HTML, CSS и vanilla JS. Без сборщика, без npm,
без единой библиотеки. Шрифты лежат локально, фото — со свободных
лицензий Wikimedia Commons.

## Что внутри

**Этажи (скролл-история):**

| # | Секция | Что там |
|---|--------|---------|
| 09 | Вход | постер, неоновая вывеска, полароиды, скрытые надписи |
| 08 | Стена | коллаж фотографий с лайтбоксом |
| 07 | Магнитофон | плеер на три трека, кассета, анализатор, караоке-экран |
| 06 | Тест | «Кто ты из подъезда?» — 4 вопроса и результат |
| 05 | Гараж | правила подъезда и генератор мудрости |
| 04 | Надписи | стена, на которой можно писать и двигать надписи |
| 03 | Пепельница | статистика действий и достижения |
| 01 | Выход | дверь на улицу и финальный оверлей |
| 00 | Подвал | секрет: найти, открыть, отпустить |

**Интерактив:**

- **Карман** внизу: сигарета, зажигалка, балтика, накотик.
  Клавиши `1—4` или клик по слоту. Выбранный предмет действует
  при клике по странице: дым, искры, пена, эффекты.
- **Зажигалка** — посвети по стене подъезда: проступают надписи.
- **Адаптивный курсор**: кольцо-окурок само меняет цвет на светлых
  блоках (бумага, фото, кислотные кнопки), чтобы не сливаться с фоном.
- **Достижения** (11 штук), счётчики и прогресс — в `localStorage`.
- **Плеер**: три трека, перемотка, громкость, живой анализатор.
  Треки включаются по клику (браузер требует жест пользователя).
- **Караоке**: на экране магнитофона появляются строки по таймингам,
  текущая строка заливается кислотным прогрессом. Это короткие
  выученные фрагменты и хуки (не полный текст песен); тайминги сняты
  по вокалу и лежат в `assets/js/lyrics.js` — можно править.
- **Тест** с четырьмя архетипами и копированием результата.
- **Стена надписей**: цвет маркера, перетаскивание, хранение в браузере.
- **Подвал**: открывается пятью кликами по двери, кликами по «18+»
  или словом «подвал» с клавиатуры.
- Прочее: частицы, тосты, секретные слова, Konami-код, скрытые надписи,
  свой быстрый плавный скролл по этажам.

## Запуск

Для локального просмотра лучше использовать сервер с поддержкой
HTTP Range — тогда перемотка музыки работает как на GitHub Pages:

```powershell
python tools/serve.py 8782
# http://127.0.0.1:8782
```

Можно и просто открыть `index.html` в браузере, но перемотка треков
на `file://` может не работать.

## Производительность

Сайт оптимизирован под слабые машины и мобильный интернет:

- фото пережаты под реальные размеры показа: **2.3 МБ → 0.82 МБ**;
- треки перекодированы в 128 kbps: **16.8 МБ → 6.7 МБ**, грузятся
  только при нажатии Play;
- убраны дорогие `mix-blend-mode` на весь экран и `backdrop-filter`
  из шапки и кармана;
- частиц меньше, DPR канваса ограничен, при скрытой вкладке анимации
  останавливаются;
- убраны предзагрузки аудио ради длительностей — они прописаны сразу;
- длительности, размеры и вес изображений зафиксированы в манифесте;
- свой скролл по якорям с ограниченной длительностью (вместо
  нативного «плавного» на 9000 px);
- `prefers-reduced-motion` уважается.

По замерам локального прогона: DOMContentLoaded ~130 мс, полная
загрузка ~230 мс, ~1.26 МБ на первый экран, 60 FPS при прокрутке.

## Структура

```

assets/css/fonts.css        локальные шрифты (Google Fonts, Cyrillic+Latin)
assets/css/base.css         токены, текстуры, типографика, каркас, HUD

assets/js/core.js           состояние, звук, частицы, карман, достижения, курсор
assets/js/player.js         магнитофон, анализатор, караоке
assets/js/sections.js       фото, тест, мудрость, надписи, подвал
assets/img/                 фото (webp) + manifest.json + CREDITS.md
assets/audio/               три mp3-трека (128 kbps)
assets/stickers/            SVG-набор (иконки и текстуры, currentColor)
assets/fonts/               woff2
tools/build-sprite.py       сборка SVG-спрайта в index.html
tools/write-photos-js.py    photos.js из manifest.json
tools/optimize-images.py    пережатие фото под размеры показа
tools/optimize-audio.py     перекодирование mp3 (нужен lameenc/miniaudio)
tools/serve.py              локальный сервер с Range, как на Pages
```

## Управление

| Клавиша | Действие |
|---|---|
| `1`—`4` | выбрать предмет в кармане |
| `M` / `Ь` | включить/выключить звук |
| `Esc` | закрыть лайтбокс / оверлей |
| «подвал» | открыть секретную секцию |
| Konami-код | пасхалка |

На телефоне карман превращается в нижнюю панель, рейл этажей скрывается.

18+. Это художественная стилизация, а не реклама и не призыв.
Алкоголь, табак и никотин вредят здоровью. Персонажи вымышлены,
подъезд тоже. Если тебе нет 18 — закрой вкладку и сделай уроки.

в `assets/img/CREDITS.md` и в футере сайта.
Треки предоставлены владельцем сайта; права принадлежат авторам.
Караоке — короткие фрагменты, права на тексты у авторов.
